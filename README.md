# 医美记录本

手机友好的医美项目记录单，纯前端，数据只在你自己设备的浏览器里。

## 功能

- **5 个分类 tab**：肉毒 / 注射填充 / 射频抗衰 / 水光皮肤 / 其他
- **手机浏览器直接打开就能填**，记录自动保存到本地
- 一键「导出 JSON」备份，「导入 JSON」恢复（换设备/换浏览器时救命）
- 编辑、删除、单条增改

## 数据隐私

- 所有记录只存在浏览器 `localStorage`，**不上传任何服务器**
- 因此 **清浏览器数据/换浏览器/换设备 = 数据丢失**
- 建议每次做完都「导出」一下，备份 JSON 文件

## 部署

`index.html` 是单页静态站，扔到任何静态托管都行。
- GitHub Pages：见仓库 Settings → Pages → 选 `main` 分支根目录，公开仓库即可免费用
- `.nojekyll` 已配置，告诉 Pages 不要走 Jekyll

## 字段

每个分类下拉一下字段即可，见 `index.html` 顶部的 `CATEGORIES` 常量。
要加字段直接在 HTML 里加一项 `{key, label, input, ...}` 就行。
